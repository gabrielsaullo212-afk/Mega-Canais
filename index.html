DÚVIDAS

Perguntas frequentes

Como os jogos são atualizados?

O servidor pode consultar uma API esportiva diariamente e entregar ao site os jogos, horários, status e escudos. A IA pode organizar a apresentação desses dados.

Os escudos dos times aparecem automaticamente?

Sim, quando a fonte esportiva configurada retorna a URL oficial/fornecida do logo do time. O navegador exibe uma imagem pequena ao lado de cada equipe.

A IA pode descobrir onde cada jogo passa?

Somente se você conectar uma fonte confiável de programação de TV/streaming. A IA não deve inventar canais ou plataformas.

Posso trocar as cores e os preços?

Sim. Todos os valores e cores principais estão concentrados no CSS e no HTML para facilitar a edição.
